========================================
    [Revenge Trainer] GUI Manual
========================================

This document explains the function and purpose of the Revenge Trainer management GUI.
While there aren't many configurable options, it focuses on the role of the GUI and what it can do.
The GUI can be opened using one of three methods: Interaction, Keypress, or Chat Command.

----------------------------------------
1. Purpose and Role of the GUI
----------------------------------------
The Revenge Trainer management GUI is designed to let players manage their wild/revenge trainer battle history. It offers several functionalities:

1-1. View List of Trainers Encountered
- Shows all trainers that the player has defeated in battle.
- Lists each trainer's name, status (whether revenge is possible), and their index number.
- You can navigate between multiple pages of trainers.

1-2. View Detailed Trainer Information
When selecting a trainer, the right panel shows detailed information:
- Name: The trainer’s name.
- Location: The trainer’s location and coordinates.
- Last Battle: The time of the last encounter with that trainer.
- Next Battle: The time when the player can battle this trainer again (based on cooldown).
- Battles: Total number of battles fought with this trainer.
- Entity Display: A visual representation of the trainer’s entity in the world.

1-3. Copy Coordinates Function
- A "📋 Copy" button copies the trainer's coordinates to the clipboard.
- A message will show on screen: “Copied: Location (x y z)”.
- Useful for waypoint systems or external record-keeping.

1-4. Delete Trainer Records
- Checkboxes allow you to select multiple trainers.
- The "🗙" button will delete all selected trainers’ records from the system.
- This action permanently removes the selected trainer’s data from the player's history.
- If the target NPC disappears, the data will be deleted as well.

1-5. Search Feature (Filter by Name)
- You can filter the list by entering part of a trainer's name.
- A reset button will return to the full list.

----------------------------------------

2. Core Features Provided by This GUI
| Feature                | Description |
|------------------------|-------------|
| Trainer List           | Displays all trainers encountered by the player. |
| Page Navigation        | Allows navigation through multiple pages of trainers. |
| Ready Status Display   | Shows if the trainer is available for a rematch (based on cooldown). |
| Detailed Info Panel    | Shows the trainer’s name, location, last battle, next battle, and entity display. |
| Copy Coordinates       | Copies the trainer's location to the clipboard. |
| Search Function        | Filters trainers by name. |
| Delete Selected Records| Deletes selected trainer records from the system. |
| Immediate Update       | The GUI is updated in real-time after any action. |

----------------------------------------
3. How to Open the GUI (Three Options)
----------------------------------------
You can open the Revenge Trainer GUI using one of three methods:

3-1. Interaction Method (Right-Click to Open)

function interact(e){
  openRevengeGui(e.player);
}
When to Use:
- Ideal when you want players to right-click a specific NPC to open the GUI.
- Example: NPCs in Pokécenters, Guilds, or Trainers in gyms.

3-2. Keypress Method (e.g., Press 'C' to Open)

function keyPressed(e){
    var key = e.key;
    if(key == 67){   // 'C' key
        openRevengeGui(e.player);
    }
}

When to Use:
- Useful if you want the GUI to be opened by a keypress.
※ You can change the key to any other key by modifying the code.

 Key IDs are numeric values mapped to actual keyboard keys.
 If you enable this option (by removing ‘//’), the player will see which key ID they pressed.
 If you want to change the key, press the desired key to check its ID, then replace the value accordingly.
 After that, add ‘//’ again to disable the display.
 Note that these key settings cannot be viewed in the vanilla keybind menu.

3-3 Chat Command Method (Enter "rev" to Open)

function chat(e){
    var msg = e.message.trim().toLowerCase();
    if(msg === "rev"){
        e.setCanceled(true);
        openRevengeGui(e.player);
    }
}

When to Use:
- Perfect for command-based interfaces where players can type to open the GUI.
- Works well if you want a more command-oriented experience for players.

3-4. Data Structure Handled by the GUI
The GUI manages trainerData stored in the player’s data, which contains:
```
uuid: Unique entity UUID
name: Trainer’s name
area: Area name
pos: {x, y, z}
lastBattle: Last battle time
nextBattle: Next possible battle time
battles: Number of battles fought
stage: Current revenge stage
firstClear: Whether the first battle has been cleared
```
The GUI performs the following operations on this data:
- Automatically sorts the data by UUID.
- Filters and searches the data based on player input.
- Updates the status based on revenge availability (cooldown).
- Displays detailed information of selected trainers.
- Deletes trainer records based on player interaction.

---

3-5. Overview of GUI Flow
1. Player triggers GUI using one of the methods (Interaction, Keypress, Chat).
2. Trainer data is loaded and organized.
3. The list of trainers is displayed.
4. Clicking a trainer’s name updates the detailed panel.
5. Player can copy coordinates for use in mapping systems.
6. Player can delete selected trainer records.
7. GUI data is immediately updated after any action.
