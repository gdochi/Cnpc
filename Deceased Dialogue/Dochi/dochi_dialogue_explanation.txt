Routes are evaluated from TOP to BOTTOM.

The system checks each route in order. As soon as one route’s condition
is satisfied, that route is executed and evaluation stops.

This means:

-   If multiple routes could be true, the FIRST matching route wins.
-   Route order defines priority.
-   More specific conditions should be placed ABOVE general ones.

Example logic order:

1.  Advanced AND conditions
2.  In-progress OR conditions
3.  Default fallback

  ----------------
  ROUTES SECTION
  ----------------

1)  First Route (AND Mode)

This route uses “mode”: “and”. That means ALL conditions inside the list
must be true.

-   FTB Condition: The FTB quest with ID 0CB0789C39C69394 must be
    completed.

-   Advancement Condition: The player must have the advancement:
    deceasedcraft:npcs/dochi

-   Stored Condition: The storeddata key “dochi_stage” must be greater
    than or equal to 3.

-   FTB Task Condition: Task index 1 inside quest 0CB0789C39C69394 must
    be completed.

Example task condition structure:

{“ftb”: {“quest”: “0CB0789C39C69394”,“task”: 1,“type”:
“completed”,“value”: true}}

If all conditions are satisfied, the dialogue will redirect to:
dochi_advanced

2)  Second Route (OR Mode)

This route uses “mode”: “or”. That means ANY one of the conditions
inside the list is enough.

-   FTB Condition: The quest 0CB0789C39C69394 must be started.

OR

-   Stored Condition: The storeddata key “dochi_flag” must equal
    “special”.

If at least one of these is true, the dialogue will redirect to:
dochi_inprogress

  --------------
  TEXT SECTION
  --------------

If none of the route conditions match, the system will display the
default dialogue text:

npc.deceasedcraft.dochi.dialogue.default

  ----------------
  CHOICE ACTIONS
  ----------------

1)  goto Moves the dialogue to another JSON file.

2)  role Triggers the NPC’s default role behavior (such as trader, quest
    giver, etc.)

3)  store Modifies the player’s storeddata.

4)  advancement Grants or removes an advancement.

5)  command Executes a Minecraft command.

6)  task Completes specific FTB quest tasks.

  ----------------------
  SYSTEM LOGIC SUMMARY
  ----------------------

-   Routes are processed in order.
-   The first valid route is used.
-   AND mode requires all conditions.
-   OR mode requires at least one condition.
-   FTB tasks can also be used as conditions.
-   Route order defines priority.
